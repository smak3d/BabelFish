# BabelFish Client

Записывает речь с микрофона (или текст с клавиатуры), отправляет на сервер и
показывает результат. Сам клиент ничего не распознаёт и не считает — вся
работа на сервере.

## Запуск

```powershell
BabelFishClient.exe [host] [port] [mic|text]
```

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `host` | `127.0.0.1` | Адрес сервера |
| `port` | `5555` | Порт сервера |
| `mic` / `text` | `mic` | Источник ввода |

Примеры:

```powershell
BabelFishClient.exe                        # локально, микрофон
BabelFishClient.exe 192.168.3.136          # сервер на другой машине
BabelFishClient.exe 192.168.3.136 8080     # непортовый сервер
BabelFishClient.exe 127.0.0.1 5555 text    # ввод текстом, без микрофона
```

Режим `text` полезен, когда микрофона нет или нужно проверить сервер, не
заставляя его слушать.

## Как пользоваться

Клиент работает циклами: ждёт команды → записывает → отправляет → показывает
результат → снова ждёт.

**Режим микрофона:**

```
<Enter>          начать запись
<Enter>          остановить и отправить
q + <Enter>      выход
```

**Режим текста:** строка, которую ты ввёл, уходит на сервер как запрос, ответ
печатается сразу.

Ошибки (сеть, распознавание, генерация) выводятся и возвращают в исходное
состояние — дальше можно работать как обычно, перезапуск не нужен.

## Формат аудио

Клиент отправляет **16 кГц, моно, PCM int16**:

```cpp
static constexpr std::uint32_t sampleRate = 16000;
static constexpr std::uint16_t channels   = 1;
```

Это согласовано со стороны сервера. Если менять — менять **обе** стороны,
иначе распознавание получит не тот сэмплрейт и выдаст мусор.

## Цепочка состояний

```
IdleState        ничего не происходит, ждёт команды
    │ BUTTON_PRESSED
    ▼
InputState       выбирает источник: клавиатура → TextRequest,
    │            микрофон → RecordingState (PCM16)
    ▼
SendingState     Request отправлен
    │
    ▼
WaitingState     ждём Response от сервера
    │
    ▼
ShowResultState  печатает транскрипцию и ответ
    │
    ▼
  IdleState      цикл замкнулся
```

Любая ошибка ведёт в `ErrorState`, который переподключается и возвращает в
`IdleState`.

## Сборка

Клиент собирается в составе основного дерева:

```powershell
cmake -S . -B build
cmake --build build --target BabelFishClient --parallel
```

Для клиента **CUDA не нужна** — она нужна только серверу. Обычная сборка
MinGW работает отдельно и ни от чего не зависит.

Понадобится PortAudio — подтягивается как сабмодуль, при первом клонировании:

```powershell
git clone --recurse-submodules https://github.com/smak3d/BabelFish.git
```

## Подключение к серверу на другой машине

1. На серверной машине разреши входящий TCP 5555 в брандмауэре.
2. Узнай её IP в локальной сети.
3. Запусти клиента с этим адресом: `BabelFishClient.exe <IP>`.

Если сервер ещё не поднят, клиент переподключится сам, когда тот появится.

## Протокол

Клиент шлёт `AudioRequest` (PCM) или `TextRequest` (UTF-8) и принимает
`Result`. Формат байтов описан в `../shared/protocol/` — там же версия
протокола. При изменении `shared/` клиент и сервер обязаны быть пересобраны
оба.
